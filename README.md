# ТАНК — полевой гайд

Полный русскоязычный гайд по роли танка в Heroes of the Storm: 12 учебных модулей, 13 досье героев, тренажёры и 388 отдельно вырезанных инфографик способностей, талантов и связок из исходного PDF.

Публичный сайт: https://onikri.github.io/hots_tank.github.io/

## Дизайн

Редакционная техническая система с асимметричной сеткой и палитрой Scarlet `#F5332C`, Black `#000000`, Creme `#CCC8B9`. Без glassmorphism, декоративных 3D-объектов и emoji; SVG-иконки — из Microsoft Fluent UI System Icons.

## Развёртывание

GitHub Actions распаковывает готовый оптимизированный статический экспорт и публикует его через GitHub Pages. Все ресурсы хранятся в репозитории — внешние токены и приватные URL не используются.

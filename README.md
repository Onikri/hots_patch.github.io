# ТАНК — полевой гайд

Полный русскоязычный гайд по роли танка в Heroes of the Storm: 12 учебных модулей, 13 профилей героев и визуальный атлас способностей, талантов и связок из исходного PDF.

Сайт собран на Next.js и автоматически публикуется через GitHub Actions в GitHub Pages. Тяжёлые оптимизированные изображения зеркалируются в Pages-артефакт во время сборки, поэтому Git-история остаётся компактной.

## Локальная проверка

```bash
npm ci
npm run build:pages
```

Публичный адрес после успешного развёртывания: `https://onikri.github.io/hots_patch.github.io/`.
